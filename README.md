# Bankers-Algorithm-Simulator
A C# project that implements the Banker's Algorithm to calculate resource allocation, detect safe and unsafe states, and determine safe execution sequences.
Banker's Algorithm Simulator


About the Project


This project is an implementation of the Banker's Algorithm in C# for Operating Systems.


The program receives resource allocation information and calculates the required matrices and vectors to determine whether the system is in a safe or unsafe state.


Features




Input Allocation Matrix


Input Maximum Matrix


Input Total Resources


Calculate Need Matrix


Calculate Available Vector


Check System Safety


Find Safe Execution Sequence


Display the calculation results




Technologies




Programming Language: C#


Application Type: Console Application


Subject: Operating Systems




Algorithm


The project uses the Banker's Algorithm to check system safety.


Need = Maximum - Allocation


Available = Total Resources - Allocated Resources
